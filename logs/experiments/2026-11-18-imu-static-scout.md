## 1. 사전등재 (실행 전)

- **질문 / 가설**: 완성된 본체를 정지 상태로 지지했을 때 MPU6050을 읽어, 목표 주기와 오류 검사를 만족하는 첫 센서 로그를 얻을 수 있는지 확인함.
- **목적 범위**: 센서 수집 경로와 로그 무결성을 탐색함. 균형 성능, 기울기 정확도, 필터 우수성은 판정하지 않음.
- **비교 대상**: 최초 수집 기준 로그를 확보함. 제어기 비교를 수행하지 않으며 성능 개선을 주장하지 않음.
- **정합 축**: 외란을 가하지 않고 같은 지지 상태를 유지함. 이번 단계는 단일 탐색 런이므로 조건 간 비교를 수행하지 않음.
- **공통 조건**: 호스트 수집률은 `SAMPLE_RATE_HZ` 한 변수의 30 Hz로 사용함. 목표 수집 창은 30초, 목표 샘플 수는 900개로 설정함. 첫 샘플부터 마지막 샘플까지의 시간차는 이상적인 경우 899/30초가 됨.
- **센서 설정**: I2C bus 1, 기본 주소 `0x68`, 가속도 범위 ±2 g, 자이로 범위 ±250 deg/s, `DLPF_CFG=5`, `SMPLRT_DIV=9`를 사용함. 내부 센서 출력률 100 Hz와 호스트 수집률 30 Hz를 구별함. DLPF 설정은 첫 수집용 가정이며 튜닝 결과로 취급하지 않음.
- **실제 적용값**: 시작·종료 레지스터 readback과 `WHO_AM_I`를 JSON에 남기고 각 필드를 검사함. 실제 호스트 주기는 CSV의 단조 시각으로 확인함.
- **전원 조건**: 학생이 배터리를 사용하며 전압 측정 기기가 없다고 알림. 이번 탐색은 실측 전압 없이 센서 읽기·저장 경로만 확인함. `--vbat`를 생략해 CSV 전압을 빈 값, JSON 전압을 null, 출처를 `unmeasured`로 남김. 추정 전압이나 예시값을 입력하지 않음. AGENTS.md §8-B의 런별 배터리 전압 조건을 충족하지 못하므로 전체 런은 전원 조건 미충족으로 무효 표시함. 센서 경로·로그 무결성의 부분 판정과 전체 런 판정을 구분하며, 성능 비교에 사용하지 않음. 이후 정식 측정은 직전 실측 전압을 `--vbat`로 입력해 수행함.
- **축·보정 상태**: 센서 축 기준 원시값과 물리량을 기록함. 장착 축·오프셋·자이로 bias가 미확정이므로 `theta_deg`, `gyro_dps`는 미측정으로 둠. 바퀴 속도와 모터 출력도 미측정으로 두며, 빈 값을 0으로 해석하지 않음.
- **기구·구동 조건**: 바퀴는 조립 상태를 유지함. 학생이 본체를 지지대로 고정해 넘어짐·굴러감을 막고, 구동 회로 상태를 확인함. 별도 모터 제어 프로그램은 실행하지 않음. 이번 수집기는 GPIO·모터 인터페이스를 호출하지 않으며, 에이전트는 실제 회로 상태를 확인한 것으로 간주하지 않음.
- **PC 사전 검증**: 가짜 I2C·가상 시각을 사용한 시험 11개를 통과함. 정상 경로에서 900샘플을 기록하고, 누락·오류 양성 대조 13가지를 검출함. 이 결과를 Pi의 실측 성능으로 해석하지 않음.
- **단계**: 학생이 장치 옆에서 탐색 1회만 실행함. 결과 보고 전 반복 수집이나 설정 변경을 수행하지 않음. 확증 반복은 이번 승인 범위에 포함하지 않음.
- **파일**: `logs/imu-first.csv`와 `logs/imu-first.csv.json`을 함께 보존함. 기존 파일이 있으면 덮어쓰거나 지우지 않고 보고함.
- **판정 기준**: 아래 조건을 모두 만족하면 센서 수집 경로와 로그 무결성만 부분 통과한 것으로 판정함. 이번 런의 배터리 전압 미측정에 따른 전체 무효 판정은 유지함. 수집기의 `COMPLETE`와 검사기의 PASS가 전체 실험 조건 충족을 의미하지 않음을 구분함.
  - CSV가 900샘플이고 tick이 0부터 899까지 연속임.
  - 시각이 엄격히 증가하고 최대 샘플 간격이 50 ms 미만임.
  - 샘플 수가 실제 시간차 × 30 + 1과 허용 오차 1% 이내로 일치함.
  - 모든 센서 샘플이 유효하고 I2C 오류 수가 0임.
  - JSON 상태가 `complete`이며 시작·종료의 설정 11개 필드가 각각 기대값과 일치함.
  - `python3 tools/check_log.py logs/imu-first.csv --rate 30 --imu`가 PASS와 종료 코드 0을 반환함.
- **중단 기준**: 첫 I2C 오류, 새 데이터 부재, 짧은 센서 응답, 주기 위반, 설정 불일치, 파일 쓰기 실패에서 자동 중단함. 예상하지 않은 움직임이나 지지 불안정이 있으면 학생이 즉시 중단함. `Ctrl+C`로 수동 중단할 수 있음. VOID 런도 두 파일을 보존하며 재시도 전에 첫 이상을 보고함.
